## 🎯 Purpose

The goal of this repository is to keep all **5th-semester academic resources in one place**.

It is intended to make it easier to:

- 📖 Revise concepts before exams
- 📝 Practice important numericals
- 🎯 Prepare from previous-year questions
- 🗂️ Keep subject material organized
- 🔄 Update notes throughout the semester
- 💻 Access study material from anywhere through GitHub

## 🧠 Study Approach

The repository is organized around a simple preparation workflow:

```text
        📚 Learn
          ↓
     📖 Review Notes
          ↓
      📝 Practice
          ↓
     🔢 Solve Numericals
          ↓
      📋 PYQs / Exams
          ↓
       🎯 Revise
```

For subjects with numerical/problem-solving components, the recommended approach is:

**Concept → Formula → Worked Example → Practice → PYQ**

This keeps the repository easy to navigate and prevents duplicate or ambiguous filenames.

## 🛠️ Markdown & LaTeX

Where appropriate, notes use **Markdown** and **LaTeX** for mathematical expressions.

Example:

```latex
$$
s = (L - 1) - r
$$
```

Matrices can be written using:

```latex
$$
A =
\begin{bmatrix}
1 & 2 & 3 \\
4 & 5 & 6 \\
7 & 8 & 9
\end{bmatrix}
$$
```

This allows equations and matrices to remain readable when viewed through compatible Markdown renderers.
