## ⚡ Fast Ingestion Pipeline: Generating & Adding Units via NotebookLM

To rapidly populate remaining units (e.g., ARVR units, AI Unit 4, FIMIS Unit 5+) and keep the repo exam-ready, follow this streamlined workflow:

```text
 ┌──────────────────────┐      ┌─────────────────────────┐      ┌────────────────────────┐      ┌─────────────────────┐
 │ 1. NotebookLM Stack  │ ───► │ 2. The 3 Golden Prompts │ ───► │ 3. UTF-8 Paste & Clean │ ───► │ 4. 1-Command Push   │
 │ (Policy+PPTs+PYQs)   │      │ (Notes, PYQs, Numerics) │      │ (VS Code + Regex)      │      │ (Instant Git Sync)  │
 └──────────────────────┘      └─────────────────────────┘      └────────────────────────┘      └─────────────────────┘
```

### 1. Source Stacking in NotebookLM
For each target unit, create a dedicated notebook with these 4 items:
1. **Course Policy / Syllabus document** *(prevents hallucinations and binds answers strictly to the NMIMS syllabus)*.
2. **Professor Slide Deck (PPTs)** for that specific unit.
3. **Previous Year Exam Papers (TEE & Mid-terms)** and official answer keys.
4. Prescribed reference textbook chapter PDF.

### 2. The 3 Golden Prompts to Generate Unit Materials

#### 📝 Prompt 1: Comprehensive Study Notes (Theory & Architecture)
```text
Act as an expert professor for SVKM's NMIMS MPSTME Computer Engineering.
Using strictly the uploaded Course Policy and Unit Slides:
1. Provide a syllabus coverage checklist table at the top.
2. Generate comprehensive, exhaustive study notes covering every single concept, definition, and architecture for this Unit.
3. Include structured comparison tables for competing concepts/technologies.
4. Represent all system architectures using clear text diagrams or Mermaid syntax.
5. Format all mathematical expressions in LaTeX ($...$ and $$...$$).
Do not summarize superficially. Write full, self-contained exam answers suitable for 5-mark and 10-mark NMIMS TEE questions.
```

#### 📋 Prompt 2: Solved PYQ Bank (High Yield)
```text
Cross-reference the uploaded Past Year Question Papers (PYQs), Mid-Term papers, and the Unit Slides.
Generate an exhaustive PYQ Question Bank for this Unit:
1. Group questions by topic and mark-weightage (2 Marks, 5 Marks, 10 Marks).
2. For each question, provide an ideal NMIMS-standard answer:
   - Bulleted key concepts
   - Highlighted keywords
   - Standard definitions and diagrams (ASCII/Mermaid)
3. Flag questions that appear repeatedly across multiple years with a "🔥 Frequently Asked" badge.
```

#### 🔢 Prompt 3: Step-by-Step Numericals Bank (AI / IVP / OS)
```text
Extract all numerical problem types, algorithms, and formulas for this Unit from the slides and past papers.
For every problem type:
1. State the standard formula in LaTeX with variable definitions.
2. Provide a 3-step solution algorithm.
3. Give 2 fully worked-out step-by-step examples with realistic NMIMS exam numbers.
4. Detail common edge cases and mistakes students make in exam calculations.
```

### 3. Clean Saving (Avoid Encoding & Citation Issues)
1. **Save as UTF-8**: Always save new `.md` files via **VS Code** (ensure `UTF-8` is displayed in the bottom-right status bar). This prevents corrupted characters like `â€”` or broken emojis.
2. **Remove Citation Brackets in 1 Click**:
   - In VS Code, press `Ctrl + H` (Find & Replace).
   - Toggle Regular Expressions (`Alt + R`).
   - Find: `\s*\[\d+\]`
   - Replace with: *(leave blank)*
   - Press `Ctrl + Alt + Enter` (Replace All) to instantly remove NotebookLM's reference numbers `[1]`, `[24]`, etc.

### 4. 1-Line PowerShell Folder Scaffolder
Quickly generate the standard unit folder and files before pasting:
```powershell
# Example: Create AI Unit 4 scaffolding in 1 second:
$subj="AI"; $unit="Unit-4"; New-Item -ItemType Directory -Path "$subj\$unit" -Force; @("study-notes", "pyq-bank", "numericals") | ForEach-Object { New-Item -ItemType File -Path "$subj\$unit\$subj-$unit-$_.md" -Force }
```

### 5. Instant Git Push
```powershell
git add .
git commit -m "Add: $subj $unit study notes and PYQs"
git push
```

## 🛠️ Recommended Tools for Exam Preparation

Get the best reading, math rendering, and revision experience from these notes:

### 1. Markdown Readers & Local Vaults
- **[Obsidian](https://obsidian.md/) (Top Recommendation)**: Open this repository folder directly as an Obsidian Vault. It natively parses math formulas ($...$ and $$...$$), renders tables cleanly, supports bidirectional links, and offers offline full-text search.
- **[VS Code](https://code.visualstudio.com/)**:
  - *Markdown All in One* (Table of contents & keyboard shortcuts)
  - *Markdown Preview Enhanced* (Renders KaTeX math + 1-click export to PDF/HTML)
  - *bierner.markdown-mermaid* (Renders inline diagrams)
- **[Typora](https://typora.io/) / [MarkText](https://marktext.dev/)**: Clean, distraction-free WYSIWYG markdown editors for quick review.

### 2. Fast PDF / Cheat-Sheet Generation
To compile notes into printable physical copies for last-minute revision outside the exam hall:
```bash
# Export using Pandoc:
pandoc OS/UNIT-1/unit1-study-guide.md -o OS_Unit1_Revision.pdf --pdf-engine=xelatex
```
*(Or use VS Code / Chrome: `Markdown Preview` → `Right Click` → `Print / Save as PDF`).*

### 3. Calculators & Solvers for Numericals
- **Casio fx-991EX / fx-991CW Emulator**: Useful for pre-exam verification of matrix operations (IVP), statistical calculations, and probability trees (AI).
- **[Mermaid Live Editor](https://mermaid.live/)**: For visualizing and practicing state machines, Gantt charts, and SDLC workflows.

### 4. Active Recall & Memorization
- **[Anki](https://apps.ankiweb.net/)**: Ideal for rapid memorization of legal sections & forensic concepts (IFS), regulatory rules & bodies (FIMIS), and 5G cellular standards.
